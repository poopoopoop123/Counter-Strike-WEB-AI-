# Counter-Strike Web AI — Zero-Dependency 3D Engine

A from-scratch browser 3D engine using only HTML, CSS, JavaScript, and the browser's built-in WebGL2 API.

## Features
- WebGL2 rendering and custom GLSL shaders
- Procedural cube mesh generation with face normals
- 4x4 matrix/vector math
- Entity/scene abstraction
- Perspective camera and mouse-look
- WASD movement, sprint, jump, and gravity
- Directional lighting with rim lighting
- Depth testing and high-DPI canvas resizing
- No external libraries, frameworks, CDNs, or assets

## Controls
WASD = move, Shift = sprint, Space = jump, mouse = look, click = capture mouse, Esc = release mouse.

Open index.html in a modern WebGL2-capable browser.
